# ქართველი AI

Android აპი, რომელიც ქართულად წერს, ასწორებს, ხსნის და გეგმავს.

## რა შეუძლია

- პოსტი, ლექსი, ესე, ტექსტის ანალიზი, ორთოგრაფია, გადაწერა
- ემეილი, რეზიუმე, ოფიციალური ტექსტი, დღის გეგმა
- ახსნა, ქვიზი, მაგალითი, გამოცდისთვის მომზადება
- JavaScript, Python, HTML/CSS, შეცდომის გასწორება, ქართული კომენტარით
- ბიზნეს იდეა, პროდუქტის აღწერა, კლიენტის პასუხი
- კაპშენი, ვიდეო სკრიპტი, მოტივაცია, დღის ჯამი

## რომ ამუშავდეს

1. Android Studio-ში გახსენი ეს პროექტი და დააჭირე Sync.
2. [Google AI Studio](https://aistudio.google.com/apikey)-ზე აიღე უფასო Gemini გასაღები.
3. აპში გახსენი პარამეტრები და ჩაწერე გასაღები.
4. მოდელი ნაგულისხმევად არის `gemini-2.5-flash`. თუ უარს იტყვის, ჩაწერე `gemini-2.5-flash-lite`.

გასაღები მხოლოდ ტელეფონზე ინახება. გამოწერის ღილაკი სატესტოა — ფული არ იჭრება. უფასო გეგმა დღეში 20 პასუხია.

ძველი Decoder PRO კოდი ამ ვერსიით შეიცვალა.
